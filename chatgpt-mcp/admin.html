tossApp · 테스트 서버 작업 승인

만료 7일의 API/Worker 배포 및 DB 마이그레이션 계획을 구분해 표시합니다. 승인 버튼은 단일 승인 영수증만 발행하며, 실제 적용은 해당 전용 MCP 도구의 별도 실행 단계입니다. 로컬 루프백 또는 승인된 tailnet HTTPS와 새 관리자 토큰 확인이 필요합니다.

채팅에서 자동 실행 허용

tossApp/tarororo-test의 API·Worker 배포와 DB 006~013 순차 적용을 채팅에서 명시적으로 실행할 수 있게 합니다. 이 설정만으로 배포나 DB 변경이 시작되지는 않습니다. 대상 설정이나 승인한 SQL이 바뀌면 다시 허용해야 합니다.

Worker / DB 013 관리 권한 명시적으로 활성화

기존 v1의 API 전용 권한을 확대합니다. 로컬 화면에서만 가능하며 개별 작업은 여전히 별도 승인해야 합니다.

DB 006~012 전용 권한 추가 활성화 (DB 변경 없음)

기존 Worker·DB 013 권한과 분리됩니다. 006~012 전용 실행 계획을 만들려면 명시적인 v3 권한 활성화가 필요하며, 실제 DB 변경은 작업별로 다시 승인해야 합니다.





















등록 대상 호스트 작업


ChatGPT가 만든 만료 7일의 계획을 확인하고 1회 승인하거나 거절합니다. 승인은 실행을 시작하지 않으며 실행은 채팅의 execute_host_operation 호출로만 진행됩니다. 승인·거절에는 로컬 루프백 또는 등록된 Tailscale HTTPS 주소와 관리자 토큰 재입력이 필요합니다. 대상 활성화 설정은 이 화면에서 바꿀 수 없습니다.

실제 실행은 별도 ChatGPT start_agent_task 호출로만 가능합니다.
    

    


    

    






    

    


    

    등록형 호스트 명령 승인
    

    

    등록된 호스트 실행 파일과 인자를 변경할 수 없으며, 빌드·외부 테스트 업로드는 각각 별도의 7일짜리 승인 계획으로 관리합니다. 정확한 작업 ID와 관리자 토큰을 입력해 한 번만 승인할 수 있습니다. 승인 자체는 명령을 실행하지 않습니다.
    

    명령 원문, 호스트 경로, 인증정보, 원시 로그는 이 화면과 채팅에 표시하지 않습니다. 외부 테스트 콘솔 업로드에는 별도 실행 단계가 필요합니다.
    

    


    

    






    

    


    

    MCP 런타임 업데이트 승인
    

    

    ChatGPT가 준비한 개인 비서 MCP 런타임 업데이트의 정확한 소스 지문·대상 스냅샷·서비스 영향을 확인합니다. 기존 터널과 관리자 서비스가 재시작돼 연결된 대화나 개발 세션이 잠시 끊길 수 있습니다.
    

    승인에는 계획 ID 직접 입력과 관리자 토큰 새 인증이 필요합니다. 승인은 실행을 시작하지 않으며, 이후 채팅의 별도 execute_runtime_rollout 호출만 승인된 버전을 설치·전환합니다. DB·Worker·Toss TEST 업로드는 포함하지 않습니다.
    



    

    






    

    

    


    

    만료형 호스트 액세스
    

    

    선택한 프로젝트는 작업 디렉터리 문맥일 뿐 접근 범위를 가두지 않습니다. 승인 시간 동안 이 MCP 설치 전체의 호출자가 호스트 사용자 권한으로 명령을 실행하며, 격리된 환경이 아닙니다.
    

    Codex 허용은 연결된 Codex 계정의 모델 사용량을 소비할 수 있지만 승인만으로 모델을 즉시 호출하지 않습니다. 실행 결과와 외부 변경은 액세스 취소로 되돌리거나 롤백되지 않습니다.
    

    sudo 그룹 멤버십은 passwordless sudo가 검증됐다는 뜻이 아닙니다. 이 화면은 passwordless sudo를 검증하지 않았습니다.
