기본은 로컬 커밋 전용입니다. Push는 이 화면에 원격·브랜치·횟수가 명시된 경우에만 포함합니다. Force Push, Reset, Amend, Merge, 브랜치 삭제, 배포와 DB 변경은 포함하지 않습니다. 파일·메시지·HEAD 검사는 계속 적용됩니다. 이 화면을 열거나 승인해도 커밋은 실행되지 않습니다.

ChatGPT 승인 카드 정보를 기다리고 있습니다.

철회는 이후 커밋을 차단합니다. 이미 실행이 허용된 커밋은 종료될 수 있습니다. 일회용 승인을 유지하려면 이 카드를 승인하지 않고 기존 개별 Git 계획을 사용하세요.
